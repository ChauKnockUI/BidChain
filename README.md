# BidChain

## Mô tả
Dự án BidChain là một ứng dụng quản lý đấu giá sử dụng blockchain, với frontend Flutter và backend Node.js.

## Cấu trúc dự án
- `backend/` - Server Node.js
- `frontend/` - Ứng dụng Flutter
- `blockchain/` - Smart contract và blockchain logic

## Cách chạy
### Backend
```bash
cd backend
npm install
npm start
